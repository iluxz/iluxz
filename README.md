### things i have personally broken so you don't have to

- `plasma-wayland-session` isn't in arch repos. it's `plasma-workspace`. always was
- stale `.sig` files from a failed gpg signing step will poison a build forever. nuke em all
- sddm's qml keyboard handler fires zero times if it's on the root rect. hook it on the username AND password fields
- qemu/KVM in a compressed loop makes the installer sit there blinking at you. don't judge the iso by its thumbnail
